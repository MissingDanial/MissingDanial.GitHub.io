Research Projects

科研项目

围绕深度学习、多模态数据融合与大语言模型解释性应用的研究实践。

基于深度学习的多模态城市声环境评估

深度学习运用 / 多模态融合 / 城市声环境

  • 背景与目标：针对传统城市声环境评估效率低下、维度单一的问题，利用街景、卫星及声学时序数据，构建基于深度学习的多模态城市声环境评估模型。
  • 行动：主导项目流程设计，完成 300+ 个城市点位的多维度声环境调研。自主研发数据处理与特征提取技术路径，实现多模态数据融合与声环境预测。应用迁移学习进行街景图像分割，利用 CNN 处理卫星图像信息，采用 PANNs 模型解析音频时序特征，并设计混合模块整合多模态数据。
  • 结果：评估模型在关键声环境指标上精准度提升约 12%，并纳入人群结构影响因素，提供了更全面、精细化的城市声环境解决方案。

使用大语言模型（LLM）改进贫困聚落识别模式

大语言模型运用 / 卫星图像理解 / 可解释识别

  • 背景与目标：为解决传统贫困聚落识别方法数据处理成本高、效率低且模型“黑箱”的问题，利用大语言模型（LLM）赋能深度学习模型，实现更高效、低成本且具备解释性的贫困聚落识别。
  • 行动：设计并实施 LLM 与 CNN 结合的贫困聚落识别方案，负责卫星图像的 LLM 语义化处理与规范化输出，并将 LLM 生成的语义特征与 CNN 提取的视觉特征进行融合，最终实现对聚落贫困倾向性的精准判定与解释。
  • 结果：数据处理量降低约 80%，识别准确率与多源数据方法相当，显著提升效率与成本效益。克服深度学习“黑箱”问题，自动生成解释性文本，为决策提供更透明的依据。
